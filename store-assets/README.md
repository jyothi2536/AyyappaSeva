# Google Play store assets

These files are the approved assets prepared for the AyyappaSeva default store listing.

- `app-icon-512.png`: Play Store app icon (512 x 512)
- `feature-graphic-1024x500.png`: Play Store feature graphic
- `phone-screenshots/`: five Android phone screenshots (1080 x 1920)

The in-app launcher source remains in `assets/icon.png` at 1024 x 1024. Keep the store icon and launcher icon visually aligned when either one is updated.
