# Ayyappa Seva

A polished Expo/React Native prototype for a multilingual Ayyappa temple community app.

## Run

Use Node.js 18 or newer.

```bash
npm install
npm start
```

Scan the QR code with Expo Go, or press `i` / `a` for an iOS / Android simulator.

## Demo admin access

The prototype uses invitation code `SWAMI108`. This is deliberately local-only. Replace it with server-side authentication and role checks before production.

## Included

- Animated devotional home screen
- Temple address and contact actions
- Telugu, Tamil, Kannada, and English UI
- PDF/audio/document upload and local viewing
- Devotee registration
- Temple updates
- Guarded admin registration and publishing area

Uploaded files, registrations, and posts live only on the device in this prototype.
